当前主要瓶颈是：模型有时不按协议输出、在资料已足够或连续无命中后继续查找，以及保守字节预算与网页/文档前部截断导致所需内容没有进入实际上下文。现有程序正确地保留并报告这些停止和失败，没有用改分数、放宽引用检查、转换参数类型或强迫作答把它们变成成功。
