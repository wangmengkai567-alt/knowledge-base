## 2. 正式实现

- `materials.py`：删除等长分配及命中块前缀优先策略。以完整行、句段、代码块为单元，按当前问题词面相关性抽取；保留邻近条件、否定和数值单位，优先题目指定的文档。网页正文优先于搜索摘要，标题只用于选择跨语言相关片段，不作为事实。每个保留片段继续对应原分块、字符范围和文档版本。
- `retrieval.py`：全局 top_k 先为不同授权知识库、再为不同文档保留过相关性闸门的候选，随后补充其他块；不扩大权限、不捏造来源，不增加检索模型请求。
- `rag.py`：从问题的显式分句列出待核查主题，按真实库、文档和版本登记词面候选与缺失。该登记不宣称语义覆盖。每批资料将历史与新原文一起重新分配，既有送模登记不改写，各轮实际保留范围另存 `active_ranges`。预算按当前完整请求、已结算用量和收尾需求计算，清除固定比例分配。
- `tool_model.py`：最终请求只保留原问题、授权范围、收尾规则和选定原文；省去工具动作、导航预览、目录和探索指令。仍是预先规划的一次严格最终生成，没有格式修复请求。
- 工具消息显示知识库和文档身份；提示词要求按缺失主题取证、多参数批量定位、资料足够后显式收尾。事件和 `run_metrics.py` 同步记录证据候选、各轮字符数、最终请求估算与实际用量。

没有采用生成式摘要，4B 未触发：成功回答所需的原文已经能在既定限制内提供，F01/F03 剩余失败来自摘录不忠实，摘要不能替代逐字校验。未增加模型阶段、摘要消耗、供应商切换、参数转换或失败兜底。
