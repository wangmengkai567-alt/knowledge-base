## 实现

- `PublicWeb` 固定组合 `TavilySearch` 与 `HTMLPageReader`。删除旧 Extract 调用、结果解析、专用超时诊断和旧类引用；没有保留两套正文读取路径、自动重试、地址轮换或浏览器渲染。
- 正文仅发出 GET，禁用环境代理和自动重定向。每次请求解析并验证全部 DNS 结果，选择一个公网 IP 固定连接，保留原域名的 Host、TLS SNI 与证书校验；收到响应后核对实际对端 IP。每次重定向重新校验地址，只允许同源，最多三次；循环、跨源或无法确认对端明确失败。外部网页只作为不可信资料处理。
- HTML 使用标准库 `HTMLParser`，不引入依赖。正文取可见的 article/main 容器，去掉导航、脚本、按钮等内容；`pre` 内逐节点连接高亮 span/code 文本，保留换行、缩进和转义字符。代码块无法完整放入输出空间时不输出半段代码。
- 接收上限为解压后 2000000 字节，HTML 节点最多 50000、嵌套最多 255 层。只支持静态 HTML；无正文容器、非 HTML、无效编码及空正文均明确失败，不执行页面脚本或跟随页面内链接。
- 正文仍最多 5000 字符、整个读取动作最多 20 秒，外层仍受 30 秒工具时限及单题 120 秒约束。正文配置改为 `AI_WEB_READER__TIMEOUT` / `AI_WEB_READER__PAGE_CHARS`，默认值没有提高。Tavily 密钥仅用于搜索。
- 诊断记录实际 HTTP 状态、连接 IP、重定向次数、最终 URL、耗时及错误类型。删除已无生产用途的 `extract_timeout_seconds`。历史结果保持原样。

IP 固定与保留域名验证使用 [HTTPCore 的 SNI 扩展](https://www.encode.io/httpcore/extensions/#sni_hostname)，DOM 文本处理依据 [Python 3.11 HTMLParser](https://docs.python.org/3.11/library/html.parser.html)。未关闭证书验证，没有发送用户授权头、Cookie 或模型私有上下文。
