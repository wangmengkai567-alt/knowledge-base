## 统一工具契约

正式工具参数和本地解析继续共用 Pydantic 模型，全部请求 `function.strict=true`。工具契约标记为 `tool_contract_version=2`；问答账本和同步/SSE 仍为 v5。

| 动作 | 当前参数与行为 |
|---|---|
| `web_search` | 一个单行、非空白的 `query`，最多 120 字符；`max_results` 为 1—5。删除旧 `keywords` 数组及每项 64 字符限制，不裁剪或改写非法参数 |
| `web_read` | `source_id`、`start`、`max_chars`；只接受本次目录编号，不接受旧 `urls`。首次读取后使用本次快照，不重新抓取 |
| `web_find` | `source_id`、字面 `pattern`；只查已读取快照，不发网络请求。返回首个命中附近的正文，以及最多 10 个原文位置 |
| `finish_research` | 单独提交 `outcome` 和实际已送模的 `citation_ids`，结束取证。尚未取证、伪造引用、与其他动作混在一批及结束后的继续调用均拒绝 |

77 字符短语通过新约束，120 字符通过、121 字符拒绝；空白、控制字符、错误类型、额外字段及旧参数均明确失败。临时诊断先在内存中执行未修改 HEAD 的旧解析器，复现 77 字符单项拒绝，再核对新解析器，没有将旧实现放回生产。

取证阶段每次都要求原生工具调用，删除原来的“探索普通文本结束”路径；模型通过显式结束动作选择依据。预算或无新证据等程序收尾仍按原有预算协议处理，原因单独保存；不增加失败后的修复调用。

结束动作属于原有 10 次工具、6 次模型调用上限，最终生成仍独立使用严格回答 Schema，不携带工具定义。最终状态须与已提交的证据选择一致，引用不能超出所选编号。网页摘要不能单独发布为正常回答；资料不足时可说明实际搜索结果。围栏代码须能在所引正文或知识库原文中找到，缺少支撑、缺少正文和选择状态不符分别记录 `UNSUPPORTED_CODE`、`WEB_BODY_REQUIRED`、`EVIDENCE_SELECTION_MISMATCH`。这不是全部事实的自动语义判定。

## 目录、快照与原文范围

用户通过 `user_urls` 明确提供的网址在会话建立时登记；搜索返回的网址随后登记，生成本次运行内稳定的 `web_1` 等编号。目录最多 53 项，对应原有最多三个用户网址及十次工具动作各最多五条搜索结果的数量边界。

每次搜索的全部有效结果元数据与摘要分开：保留编号、URL、标题、发现时间、来源和正文读取状态。摘要受限时目录仍可选择；摘要为空也保留目录，不能生成空证据或伪造引用。目录不是事实依据，不能用目录编号代替正整数引用编号。

HTML 解析改为先生成有上限的完整规范正文及代码块范围，再按需取窗口。单页解压响应和解析正文均不超过 2000000 字节，本次快照正文 UTF-8 合计最多 8000000 字节；目录与代码范围等元数据另占空间。缓存仅属于一次运行，不跨运行复用，不支持恢复执行。

单次读取窗口仍最多 5000 字符，当前工具结果仍遵守 8000 字符及 12000 字节消息上限，整次模型请求仍按 16000 UTF-8 字节估算预检。字符范围采用 Python Unicode 字符索引，`start` 含、`end` 不含。窗口起点落在代码内时回到该代码块起点；完整代码无法容纳时明确失败，后续工具及模型材料裁剪也不输出半段代码。纯空白范围不能成为证据。

实际送模窗口保存 `source_id`、原始 URL、获取时间、`start/end`、完整正文字符数及代码范围；同版正文的已提供重叠范围去除后仍保留精确映射。完整快照单独保存到既有七天运行记录，**不**发送给模型。原 HTTP 成功后若快照容量或窗口范围失败，错误继续保留已取得的 HTTP 状态与诊断。

目录更新、命中位置、证据选择同步进入事件与快照；API 的网页来源包含范围，前端独立展示“发现的网页”和实际引用资料。旧历史 JSON 不改写；离线评测识别旧契约和新契约，新契约按保存的规范调用键核对重复动作，并对正文窗口逐段核对本次完整快照。
