## 改动

- `WebRegistry.find()` 不再选择首个命中并附带大段正文；现在只返回最多 10 项导航命中。每项包含来源编号、匹配字符范围、最多 120 字符的原样预览及预览范围、`in_code` 标记。
- 删除旧 find 的正文窗口逻辑和 `size` 参数，调用入口统一使用新的导航结果。新增 `WebMatch` 类型明确结果字段。
- `web_find` 有命中时记为成功，没有命中时记为空结果。导航预览不加入 `sources`，不分配引用编号，不登记为已送模的引用证据。
- 原生工具循环按新出现的 `(source_id,start,end)` 位置记录导航进展。连续两次有效查找不会因正文列表为空而被误判为无进展；空查找仍遵守原有终止规则。
- 模型通过现有 `web_read(source_id,start,max_chars)` 读取选定位置的小窗口；后续读取继续使用本次固定快照，保留原文范围和完整代码块要求。无需引入第二套读取接口。
- 同步工具说明、取证系统提示、RAG 模板及评测说明，明确预览不可引用；独立子问题可以在同轮发出多个查找或读取动作。API、SSE 外层字段保持原样。

主要实现：[网页快照与导航](../../ai-service/internal/biz/web_sources.py)、[工具执行与成功状态](../../ai-service/internal/biz/tools.py)、[循环进展判断](../../ai-service/internal/biz/rag.py)、[工具结果类型](../../ai-service/internal/biz/tool_types.py)。
