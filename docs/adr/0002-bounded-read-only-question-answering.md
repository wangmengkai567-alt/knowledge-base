# 第一版使用有上限的只读工具问答

状态：已确认，2026-10-27。

第一版由现有 Python 后端直接管理一个智能体执行循环，使用千问对话能力和 Tavily 搜索、正文提取；首批不额外接入其他外部工具。用户开启联网后，后端可以根据问题选择只读工具，外部搜索只发送必要关键词。当前没有恢复执行和长时任务需求，因此不引入 LangGraph 或第二套执行引擎。

模型可以决定下一步获取什么信息，程序负责执行上限和明确终态。最终回答中的事实性结论必须对应实际使用的资料，不能仅在回答末尾附上相关链接。过程状态实时发送，答案在引用检查后发布；不在第一版展示未核验的逐字草稿。

用户已经确认执行次数、时间、输入输出预算及本地证据保留期限，具体数值统一记录在 [准备报告](../preparation/preparation-report.md#已确认的执行基准)。这些是下一阶段实现的约束，不表示当前旧问答代码已经具备执行循环或预算控制。

Tavily 的密钥配置和接线在第二阶段完成。按照用户最新要求，准备阶段不调用网页接口做连通测试。
