# RAG 黄金评测集

题目只根据语料里**有正文且大于 1KB 的 Markdown** 出。下面这些空文件或 ≤1KB 的目录页**不要当成可答来源**：

- `LeetCode/LeetCode.md`（空）
- `Harness/harness.md`、`RAG/RAG.md`（几乎空）
- `RAG/question.md`（只有题干，无答案）
- 各库首页：`Agent.md`、`AI 应用开发.md`、`后端开发.md`、`计算机基础.md`

`04.Docker.md`、`06.数据结构.md`、`08.异步编程.md` 已有正文，可以出可答题。`golden_set.json` 现为 100 条（90 可答 / 10 拒答）。


评测脚本会登录后拉知识库列表，按每题的 `relevant_filenames`（找不到再用 `kb_hint`）自动选库。顶层 `"knowledge_base_id": null` 不用填。`relevant_filenames` 按实际上传文件名核对。

## 指标

| 指标 | 算法 |
|------|------|
| Hit@5 / Hit@10 | retrieve top-K 是否出现 `relevant_filenames` 中任意一篇 |
| MRR | 第一篇相关文档排名倒数 |
| 答案正确率 | `must_contain` 是否都出现在回答里。比较前去掉空白和「的」，并把「还没有 / 尚未 / 没有」看成「未」、「不算 / 并非」看成「不是」、「黑匣子 / 黑箱」看成「黑盒」、「不是同一套（数字）」看成「不一样」 |
| 幻觉率 | 回答里有证据推不出的断言 / **有回答的条数**（拒答不算） |
| 拒答正确率 | `answerable=false`（资料内没有答案）且整句「我不知道」 |
| 漏召回 | 资料内有答案，却回答「我不知道」（不算幻觉） |

幻觉看的是「证据能不能推出这句话」，不是「这句话是否在检索块里原样出现」。

支撑范围是这次检索命中的分块，再加上生成时会一并送给模型的左右邻块（与 `rag.context_window` 一致）。同义转述、概括、调换语序都算有支撑。下面这些仍算幻觉：

- 句子和证据几乎没有共同实词，也对不上证据里的术语
- 句子里出现了证据中没有的数字（带单位，或两位及以上）
- 踩中该题的 `hallucination_traps`
- 资料里没有答案，却给出了实质回答

「资料没有写」「根据资料如下」这种引出句，以及不足一句的标题、表头、中英对照，不单独算断言。证据里已经有的术语（如 `nil` / `panic` / `Token Cost`），换一种中文说法仍然算转述。`python eval/run_eval.py --rescore` 会用已有回答按新标准重算，不再次调用模型。

同一时间只允许一轮评测：脚本启动时会锁住 `eval/.run_eval.lock`，已有一轮在跑（哪怕终端已关闭、进程还活着）时，新的一轮会报出占用者的 pid 并退出，不会重复消耗接口额度。进程退出后锁由系统自动释放，无需手动删除。

`answerable` / 「资料内有答案」只表示**文档里有没有答案**，不是题干是非问的「是/否」。例如 A04 问「有 stderr 就等于失败吗」，资料内有答案 = 是，但正确答案是「不等于失败」。
